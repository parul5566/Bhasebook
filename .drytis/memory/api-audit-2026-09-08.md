## Incident during audit: MySQL InnoDB corruption
- At 20:13 the live DB's `users` table threw **1030 "Tablespace is missing"** on every SELECT → every login 500'd. A stray `friendships.ibd` remained after an earlier `DROP DATABASE` (errno 39), and the whole datadir had corrupt redo logs.
- Root fix: stopped app queue worker → `sudo rm -f /var/lib/mysql/{ib_logfile*,ibdata1,ib_buffer_pool,undo00*,aria_log.00000001,ddl_recovery.log}` + `#innodb_redo/*` + both DB dirs → `procmgr restart mysql` → recreate both databases with root grants → `migrate --force` + `db:seed --force`.
- Both DBs (live `u1690p3409_bhasebook` + test `u1690p3409_bhasebook_test`) recreated fresh. All data is seeded demo data — nothing irreplaceable was lost.
